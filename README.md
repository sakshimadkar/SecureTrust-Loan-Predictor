# 🏦 SecureTrust : Intelligent Loan Approval Predictor

## 📌 Project Overview
An end-to-end Machine Learning pipeline to automate the loan approval process for **SecureTrust Bank**. This system analyzes applicant data to predict whether a loan should be **Approved** or **Rejected**, helping the bank reduce financial risks and manual processing time.

## 🚀 Key Features
* **Exploratory Data Analysis (EDA):** Identified key patterns and correlations in historical loan data.
* **Data Preprocessing:** Handled missing values, applied data encoding, and used Standard Scaling.
* **Model Building:** Trained and evaluated multiple classification models (Naive Bayes & KNN) on real-world data.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Scikit-Learn
* **Environment:** Jupyter Notebook

## 📊 Results
* **Naive Bayes Classifier:** Achieved **86.5% Accuracy** (Best performing model).
* **K-Nearest Neighbors (KNN):** Achieved 75.5% Accuracy.
* The system is fully tested and capable of classifying individual customer applications as "Approved" or "Rejected" in real-time.
